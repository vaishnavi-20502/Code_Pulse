# CodePulse

CodePulse is a full-stack web application that tracks and visualizes coding activity using LeetCode data.

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Chart.js

## Features
- Fetch LeetCode user stats
- Problem difficulty distribution (Easy/Medium/Hard)
- Interactive dashboard using charts
- Backend API integration
- MongoDB data storage

## How to Run

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm start
